# dsh-clawd-pet

> 中文内容已统一放在 [README.md](README.md)（本仓库以中文为主文档）。本文件仅为兼容旧链接而保留。

简要说明：本项目是 DeepSeek Harness（DSH）的 Cordis 插件，让 Clawd on Desk 桌宠实时反映 DSH 的会话状态（思考、调工具、等审批、出错、完成等）。项目借鉴上游 [rullerzhou-afk/clawd-on-desk](https://github.com/rullerzhou-afk/clawd-on-desk)（AGPL-3.0）的架构与本地上报协议，仅新增了 DSH 侧桥接库；桌宠应用本体不包含在本仓库内，需另行安装。

For English readers: this repo contains only the DSH-side bridge plugin — the Clawd on Desk pet app itself is not bundled here and must be obtained from its official (closed) distribution channel.
